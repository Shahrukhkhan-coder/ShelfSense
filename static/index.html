      How It Works

      1. Select a book from the trained catalogue.
      2. The title is located in the book-feature pivot table.
      3. The nearest-neighbor model compares its feature vector with other books.
      4. The five closest titles are returned.

      Recommendation Method

      Each title is represented by its values in the trained book dataset. The selected book's feature vector is sent to a nearest-neighbor model, which finds nearby book vectors, excludes the selected book itself, and returns the next five titles.

      Limitations

      • A title must exist in the trained dataset.
      • Recommendations depend on the available dataset.
      • Results are not based on live popularity.
      • Similarity does not guarantee personal enjoyment.
      • The model does not replace human literary judgment.
      • The system may not recognize alternate spellings or editions.
